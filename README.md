# Labguide 3 — Computer Conversations

Hands-on **Computer Conversations** lab material for DevRev (part **3** of the trilogy): building **IT Support** and **HR** agents with a **categorization agent** and workflow that routes questions and uses **HTTP/REST API** calls.

## What's in this repo

- **`docs/`** — Markdown lab pages (screenshots under `docs/images/`).
- **`mkdocs.yml`** — [MkDocs Material](https://squidfunk.github.io/mkdocs-material/) site config.

Modules cover **creating and configuring agents**, **workflow creation**, **testing via conversation**, and **workflow log review** for troubleshooting.

## Local preview

```bash
pip install mkdocs-material
mkdocs serve
```

Open the URL shown in the terminal (e.g. `http://127.0.0.1:8000`).
